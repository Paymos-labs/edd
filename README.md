# Paymos for Easy Digital Downloads

WordPress payment gateway for Easy Digital Downloads.

The package generated by Paymos Dashboard includes:

- Sandbox and live API credentials in `paymos-config.php`
- Paymos webhook secrets
- Paymos PHP SDK bundled under `vendor/paymos/php-sdk/src`
- A local `vendor/autoload.php`

No Composer install is required on the WordPress server.

## Runtime Flow

1. Customer selects Paymos during EDD checkout.
2. The plugin creates a pending EDD payment.
3. The plugin creates a Paymos invoice and redirects the customer to hosted checkout.
4. Paymos sends a signed webhook to `/wp-json/paymos-edd/v1/webhook`.
5. The plugin verifies signature, event idempotency, environment, project, amount, currency, and terminal invoice state before completing the EDD payment.

## Requirements

- WordPress 6.2+
- Easy Digital Downloads 3.x
- PHP 7.4+
- Public HTTPS store URL
